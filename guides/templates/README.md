# Templates Index

Last updated: 2026-05-03.

Use these templates to keep cross-repository documentation consistent.

## Available templates

- [Capability analysis template](./capability-analysis-template.md)
- [Architecture document template](./architecture-document-template.md)
- [Operations runbook template](./operations-runbook-template.md)
- [Repository documentation template](./repository-documentation-template.md)

## Selection guide

- use the capability template when documenting end-to-end behavior across repositories
- use the architecture template when documenting structure, boundaries, and design consequences
- use the runbook template when documenting execution, validation, and recovery steps
- use the repository template when normalizing a repo README or repo-local docs set
